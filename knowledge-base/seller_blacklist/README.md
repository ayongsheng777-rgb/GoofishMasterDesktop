# 黑名单知识库说明

本目录用于存放黑名单卖家的补充语料（可选）。

## 工作机制

- 运行时黑名单存储在 **Postgres `blacklist` 表** 中，通过飞书指令「拉黑 + 卖家名」或 API `POST /api/blacklist/add` 添加。
- agent-pipeline 在搜索和监控流程中自动过滤黑名单卖家的商品（按 seller_id / seller_name 模糊匹配，60 秒缓存）。
- 本目录下的 .md 文件会作为 RAG 语料向量化，用于在 AI 风险分析时提供"相似案例"上下文（例如某类高危卖家的行为模式），不直接参与过滤。

## 语料格式建议

每个 `## 二级标题` 为一个知识块，描述一类高危卖家模式，例如：

```markdown
## 某类高危卖家行为模式
特征描述：……
历史案例：……
处置建议：……
```
