① OTP 验证器（管理后台登录保护）

管理后台（http://127.0.0.1:8911）开启了 TOTP 动态口令保护。首次访问会显示一个二维码 / 密钥，用下面任意一款验证器 App 扫码添加，之后每次登录输入 App 里显示的 6 位动态码即可。验证器账户名为 GoofishMasterDesktop。

💡 扫码失败时可选择「手动输入密钥」：把页面上那串 Base32 密钥（形如 JBSWY3DPEHPK3PXP）填进验证器即可，效果相同。动态码每 30 秒刷新一次，请确保电脑与手机时间大致准确（误差过大会提示口令错误）。

② 飞书扫码登录 与 快捷指令菜单配置

2.1 创建飞书自建应用（一次性）

1

打开 飞书开放平台，登录后进入「开发者后台」→「创建企业自建应用」，名称随意（如「闲鱼圣手」）。

2

在应用的「凭证与基础信息」页复制 App ID 与 App Secret。

3

「权限管理」中开通消息权限：im:message、im:message:send_as_bot、im:resource（发送图片/卡片需要）。

4

「事件订阅」的订阅方式选择 使用长连接接收事件（本项目优势：无需公网 IP / 回调域名），添加事件「接收消息 im.message.receive_v1」。

5

「应用发布」中创建版本并发布（企业内自建应用一般自动通过），然后在飞书里找到这个机器人，发一条消息建立会话。

2.2 在本软件中绑定

打开管理后台「🏠 首页 / 飞书配置」卡片，点击「获取二维码」→ 用飞书 App 扫码 → 按提示填入 App ID / Secret 完成绑定。绑定成功后机器人自动建立长连接，你的飞书账号（open_id）会登记为推送对象。

💡 「重新配置」按钮会彻底清空飞书配置（断开长连接、删除凭证文件、清空 config.json 中的 feishu 段），无残留，可放心重配。

2.2.1 更简方式：飞书 App 内一键绑定

除了上面手动填 App ID / Secret，你也可以走更省事的方式：在管理后台点「获取二维码」→ 用飞书 App 扫码 → 按页面提示，既可以「新建机器人」直接创建并绑定，也可以「选择已建好的机器人」完成授权。选定后系统自动拉取凭证并立即启用，全程无需手动复制粘贴 App Secret，适合不熟悉开放平台的用户。

③ 代理设置

调用境外模型（如 Gemini / OpenAI）或网络受限时，需要配置代理。本机运行的代理直接填 127.0.0.1 地址即可。

配置入口（二选一）

  • 管理后台（推荐，即时生效）：「🧠 AI 模型配置」页 → 顶部「全局代理地址」，填入如 http://127.0.0.1:1080，保存即热生效，无需重启。
  • 配置文件：config.json 的 ai.proxy_url 字段，改完需重启服务。

常见问题

  • 代理软件默认端口各不同（1080 / 7890 / 10809…），以你本机代理软件的「允许局域网连接 / 混合端口」设置为准。
  • DeepSeek、通义 Qwen、智谱、Kimi 为国内服务，直连即可，不必走代理；Gemini、OpenAI 为境外模型，必须走代理。
  • AI 配置页里每个 provider 有「走代理」勾选：勾选 = 该模型经全局代理访问；不勾 = 直连。

⑤ 模型配置简要说明

配置页结构（管理后台「🧠 AI 模型配置」）

  • 启用开关 + API Key：填入对应平台的密钥即启用该模型。
  • 模型选择：每个 provider 下拉里选具体型号（如 deepseek-chat / qwen-vl-max / gemini-2.0-flash）。视觉类任务建议选带视觉能力的型号。
  • 走代理：境外模型勾选（配合全局代理地址）。
  • 任务路由规则：指定不同类型任务用哪个模型（文本分析 / 图像识别 / embedding 等），不懂就保持默认。

生效方式

  • API Key、模型选择、代理地址：保存后即时热生效，自动同步到 AI 路由，无需重启。
  • 端口、AI 并发数等基础设置：修改 config.json 后需重启服务生效。

省钱建议

  • 日常分析用 DeepSeek 足够便宜；Gemini 只留给需要看图的任务。
  • 监控任务反复扫到的商品有去重（同一任务内不会重复分析），但不同任务各自计费，别用多个任务盯同一个关键词。

⑥ 闲鱼登录方式说明

搜索与监控都依赖闲鱼登录态（未登录会撞登录墙、抓 0 条）。有两种登录方式，任选其一：

方式一：管理后台扫码（推荐）

1

打开管理后台「🐟 闲鱼登录」标签页。

2

点击「获取二维码」，用手机闲鱼 App 扫码并确认登录。

3

页面显示「已登录」即完成。登录态保存在本机数据目录（data/spider-state/），重启不丢。

方式二：飞书指令登录（飞书已绑定时）

如果飞书已经配置好，无需打开管理后台——直接在飞书私聊机器人发送 闲鱼登录，机器人会把闲鱼扫码二维码直接推送到对话里，用手机闲鱼 App 扫码确认即可完成登录，与方式一效果完全相同。

注意事项

  • 登录态有有效期（闲鱼风控策略决定，通常数天到数周）。过期后搜索会明确提示「登录态已过期」，回来重新扫码即可。
  • 频繁采集容易触发风控验证（滑块）。触发后系统会如实提示，暂停一阵再试，别连续猛扫。
  • 同一时刻只允许 2 个扫码会话（防资源泄漏），失败会话会自动回收。
