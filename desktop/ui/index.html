关于 GoofishMasterDesktop 桌面控制台

飞书智能体二手商品情报系统的本地桌面运行端。四个微服务（飞书智能体 / AI 路由 / 分析编排 / 采集服务）由本程序统一编排、健康巡检并优雅关停，无需安装 Python 或外部数据库。

数据目录即配置、日志与运行状态落盘位置；AI Key 与飞书凭证请在 config.json 中填写后重启。

项目地址：github.com/ayongsheng777-rgb/GoofishMasterDesktop
